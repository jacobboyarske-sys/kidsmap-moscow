# KidsMap Moscow — учебный проект

Карта детских событий Москвы на Streamlit: фильтр по датам, категориям и возрасту,
классификация событий (правила + ML), сбор данных с сайтов афиш.

**Главная цель проекта — не сама карта, а то, что вы её построите сами, используя
Claude Code как ассистента.** Код за вас никто не пишет — вы формулируете задачу,
смотрите, что предлагает Claude Code, проверяете и правите.

Каждый этап оформлен отдельным файлом `туториал_N.md` в этой папке — по мере
прохождения появляется следующий номер.

## Как вообще работать с Claude Code в этом проекте

Несколько привычек, которые стоит закрепить с первого дня:

1. **Маленькие задачи.** Не просите "сделай весь проект" — просите "добавь фильтр по
   дате в сайдбар" или "напиши функцию, которая парсит JSON события в pydantic-модель".
   Чем уже задача, тем проще проверить результат.
2. **Plan Mode для больших шагов.** Перед тем как начинать новый этап (например,
   "сделать ML-классификатор"), включите режим планирования (Shift+Tab до "plan mode"
   или команда `/plan`) и попросите Claude Code предложить план — сначала обсудите
   план, потом разрешайте писать код.
3. **Всегда читайте diff перед принятием.** Даже если код выглядит рабочим — это
   тренировка чтения чужого (машинного) кода, полезный навык сам по себе.
4. **CLAUDE.md — память проекта.** В корне проекта есть `CLAUDE.md` с описанием
   проекта, структуры и соглашений. Claude Code читает его автоматически в начале
   сессии — обновляйте его, когда меняются договорённости.
5. **Коммитьте после каждого этапа.** Просите Claude Code помочь сформулировать
   commit message, но проверяйте `git status`/`git diff` сами перед коммитом.
6. **Спрашивайте "почему", а не только "как".** Если Claude Code предлагает решение —
   просите объяснить альтернативы ("почему TF-IDF, а не просто ключевые слова?").
   Это и есть восстановление навыков, а не просто рабочий продукт.

## Дорожная карта по туториалам

| Файл | Тема | Статус |
|---|---|---|
| [туториал_1.md](туториал_1.md) | Окружение и первое знакомство с Claude Code | готов |
| [туториал_2.md](туториал_2.md) | Модель данных и seed-датасет | готов |
| туториал_3.md | Streamlit MVP: таблица + карта | план |

| туториал_5.md | ML-классификация | план |
| туториал_6.md | Сбор данных с сайтов (скрапинг) | план |
| туториал_7.md | Автоматизация и полировка (опционально) | план |

Краткое содержание будущих этапов:

- **Модель данных и seed-датасет** — pydantic-модель `Event`, вручную собрать
  20-30 реальных событий с сайтов афиш в `data/seed_events.json`.
- **Streamlit MVP** — таблица + карта (`streamlit-folium`), фильтр по датам.
- **Категории и возраст** — ручная разметка + фильтры в сайдбаре.
- **ML-классификация** — TF-IDF + LogisticRegression для типа развлечения,
  regex-правила для возрастных ограничений.
- **Скрапинг** — парсеры под 1-2 сайта (`requests` + `BeautifulSoup4`),
  де-дупликация, автотэгирование через классификатор.
- **Автоматизация** — запуск по расписанию, полировка UI, опциональный деплой.

## Примерный тайм-лайн

При 1-2 сессиях в неделю по 2-4 часа весь проект (туториалы 1-6) укладывается в
4-6 недель — то есть можно закончить до выхода на работу в октябре, оставив
туториал 7 уже "для души".

## Что можно скорректировать

- **Источники данных**: playforsoul.ru/afisha, mozart-for-kids.ru, msk.mamahod.ru —
  ориентировочный список, замените на любые удобные (например, afisha.ru/msk,
  mos.ru/afisha, kudago.com/msk).
- **Категории/возрастные группы**: предложенные — отправная точка, а не канон.
- Если 20-30 событий вручную — это слишком долго, можно взять 10-15, эффект для
  обучения (ML, фильтров) не пострадает.
