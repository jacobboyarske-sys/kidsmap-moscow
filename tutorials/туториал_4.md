# Туториал 4. Категории и возраст — фильтры, синхронизация карты и таблицы

(~2-3 часа)

Цель этапа — дополнить фильтр по датам ещё двумя (категория, возраст) и связать
карту с таблицей: клик по маркеру подсвечивает соответствующую строку в таблице.
Обратная синхронизация (клик по строке → подсветка на карте) сознательно отложена
на будущее — на этом этапе делаем только одно направление: карта → таблица.

Как и раньше: код пишете вы сами вместе с Claude Code — ниже объяснение концепций и
формулировки задач, а не готовые файлы для копирования.

## Шаг 1. Собрать фильтрацию в одну функцию

Сейчас в `app.py` фильтр по датам — это отдельная строка `[e for e in events if
date_from <= e.start_date <= date_to]` прямо в теле скрипта. Прежде чем добавлять
ещё два критерия (категория, возраст), стоит собрать всю фильтрацию в одну функцию
— иначе в `app.py` будет три похожих цикла подряд, и легко забыть применить один из
критериев в одном месте, а в другом нет.

Предлагаемая сигнатура в `src/data.py` рядом с `load_events`:

```python
def filter_events(
    events: list[Event],
    date_from: date,
    date_to: date,
    categories: list[Category],
    age_limits: list[AgeLimit],
) -> list[Event]:
    ...
```

Внутри — один проход по `events` с проверкой всех условий сразу (`and` между
условиями), а не последовательные `filter_by_date()` → `filter_by_category()` →
`filter_by_age()`: для трёх простых условий на маленьком датасете это не вопрос
производительности, а вопрос читаемости — один явный список условий нагляднее, чем
цепочка промежуточных списков с похожими именами.

## Шаг 2. Мультиселект по категориям

`st.sidebar.multiselect("Категории", options=list(Category), default=list(Category))`
— по умолчанию выбраны все категории (иначе при первом открытии приложения
пользователь увидит пустую карту и решит, что что-то сломалось). `Category` — Enum,
и `multiselect` умеет работать со списком Enum-значений напрямую, но подпишет их в
интерфейсе через `str(...)`/`.value` — проверьте глазами, что в виджете видно
понятные подписи ("театр", "концерт"...), а не `Category.THEATRE`.

## Шаг 3. Мультиселект по возрасту

Аналогично для `AgeLimit`: `st.sidebar.multiselect("Возраст", options=list(AgeLimit),
default=list(AgeLimit))`.

## Шаг 4. Подключить оба фильтра

Замените текущий однострочный фильтр по датам на вызов `filter_events(...)` со
всеми четырьмя параметрами. Проверьте, что `filtered_events` по-прежнему единый
источник данных и для таблицы, и для карты (это уже было так в туториале 3 — важно
не сломать при рефакторинге).

## Шаг 5. Клик по маркеру подсвечивает строку в таблице

Самый нетривиальный шаг — здесь стоит явно спросить Claude Code свериться с
актуальной документацией Streamlit (`developing-with-streamlit` скилл), а не
полагаться на память: API событий выбора (`on_select`) относительно новый и
различается между виджетами карт.

**Важная находка (получена эмпирически при первой попытке):** у `st.plotly_chart`
с картой на `px.scatter_map` (MapLibre-трассы) клик по маркеру **не генерирует**
событие выбора — `event.selection` остаётся пустым независимо от точности клика.
Это ограничение самого Plotly (`scattermap`/`scattermapbox`-трассы не поддерживают
клик-выбор так же, как обычные `scatter`), а не баг в коде — если столкнётесь с тем
же на своей версии Plotly, не тратьте много времени на отладку координат клика,
переходите к варианту ниже.

Рабочий вариант — **`st.pydeck_chart`** (deck.gl, тоже нативный виджет Streamlit,
идёт в комплекте с самим Streamlit, отдельно ставить не нужно):

1. Слой точек — `pdk.Layer("ScatterplotLayer", data=map_df, id="events",
   get_position=["lon", "lat"], get_fill_color=[...], pickable=True)`. **Важно:**
   `id` у слоя обязателен, если включаете `on_select` — иначе состояние выбора не
   сохранится между перезапусками скрипта.
2. `event = st.pydeck_chart(deck, on_select="rerun", selection_mode="single-object",
   key="map")` — включает события выбора при клике.
3. `event.selection.indices` — словарь `{"<id слоя>": [индексы]}`, то есть
   `event.selection.indices.get("events", [])`.
4. Так как карта и таблица строятся из **одного и того же** списка
   `filtered_events` в одном и том же порядке, индекс точки на карте — это и есть
   индекс строки в таблице. Не нужен отдельный id-поле в `Event` для связи.
5. Подсветить строку в `st.dataframe` — через `pandas.Styler`
   (`df.style.apply(...)`) с подсветкой фона нужной строки, переданный в
   `st.dataframe`.

Если и это на практике окажется неудобным — не страшно упростить до, скажем,
`st.write` с текстом "Выбрано: {title}" под картой вместо подсветки строки
таблицы; сама идея связи карта→данные важнее конкретной визуализации подсветки.

## Шаг 6. Запуск и проверка глазами

```powershell
streamlit run src/app.py
```

Проверьте:
- снятие всех категорий, кроме одной — карта и таблица показывают только события
  этой категории;
- снятие всех возрастов — пусто, без падения (тот же паттерн, что и с пустым
  диапазоном дат в туториале 3);
- клик по маркеру на карте — видно, какая строка в таблице подсветилась/помечена
  как выбранная, и что это действительно то же событие (по названию).

## Как использовать Claude Code на этом этапе

- Для шага 5 явно попросите свериться с документацией через скилл
  `developing-with-streamlit`, прежде чем писать код — API выбора для
  карт/графиков относительно новый и различается по виджетам.
- Спросите, почему индекс точки на карте можно напрямую использовать как индекс
  строки таблицы — при каком условии это сломается (подсказка: если `map_df` и
  `df` для таблицы вдруг перестанут строиться из одного и того же
  `filtered_events` в одном порядке, например если один из них досортировать).
- Если подсветка через `Styler` не работается — не упирайтесь, обсудите с Claude
  Code упрощённый вариант (см. конец шага 5).

## Проверка

1. `filter_events()` в `src/data.py` принимает даты, категории и возраста, и
   `app.py` больше не содержит "голого" списочного выражения для фильтрации.
2. Мультиселекты по категориям и возрасту в сайдборде — по умолчанию выбрано всё.
3. Снятие категории/возраста реально сужает и таблицу, и карту одновременно.
4. Клик по маркеру на карте видимо выделяет соответствующее событие в таблице.
5. Сделан коммит (`git add src/ tutorials/ && git commit -m "..."`).
