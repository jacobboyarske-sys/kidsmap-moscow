# Туториал 7. Полировка UI и деплой

(~2-3 часа)

Цель этапа — сделать приложение приятнее глазу (иконка, цвет маркеров по
категории) и вынести его за пределы `localhost:8501`, чтобы показать кому-то
ссылкой. Туториал опциональный ("для души") — из трёх исходных блоков
(расписание/полировка/деплой) сейчас делаем полировку и деплой, расписание
сознательно отложено.

Как и раньше: код пишете вы сами вместе с Claude Code — ниже объяснение концепций и
формулировки задач, а не готовые файлы для копирования.

## Часть A. Полировка UI

### Шаг 1. Иконка и заголовок вкладки

`st.set_page_config(page_title="KidsMap Moscow", page_icon="🗺️", layout="wide")` —
сейчас `layout="wide"` уже есть, добавьте `page_title`/`page_icon` рядом. Без
`page_title` вкладка браузера показывает голое "Streamlit" — мелочь, но заметная.

### Шаг 2. Цвет маркеров по категории + легенда

Сейчас все маркеры на карте — фиксированный красный цвет (`get_fill_color=[220,
60, 60]`), категорию видно только в таблице. Задача: каждой категории — свой цвет.

1. Словарь `CATEGORY_COLORS: dict[Category, list[int]]` — по цвету (RGB) на
   каждую из 8 категорий.
2. В `map_df` добавить колонку `color` — `[CATEGORY_COLORS[e.category] for e in
   filtered_events]` — pydeck умеет брать цвет из колонки датафрейма по имени
   (`get_fill_color="color"`), а не только фиксированный список на все точки.
3. Легенда — у pydeck нет встроенного виджета легенды. Простое решение:
   `st.sidebar` (или под картой) с цветным квадратиком/эмодзи на каждую
   категорию через `st.markdown` с инлайн-CSS или `st.color_picker` в
   read-only-стиле — обсудите с Claude Code, какой вариант проще для 8 категорий,
   не переусложняя.

### Шаг 3. Причесать сайдбар (по мелочи, на ваше усмотрение)

Не обязательный чеклист, а список идей, если будет желание: подписи фильтров
покороче, разделители между блоками фильтров, сворачиваемые секции
(`st.expander`) если сайдбар станет тесным после добавления легенды.

## Часть B. Деплой

### Шаг 4. Закоммитить эмбеддинги

`data/event_embeddings.npy` сейчас в `.gitignore` — на Streamlit Cloud негде
заранее запустить `embed_events.py`, поэтому без закоммиченного файла поиск по
смыслу на деплое не заработает (деградирует до "недоступен", не до падения — мы
это уже предусмотрели в `search.py`, но лучше не терять фичу). Файл маленький
(~164 КБ на 131 событие) — уберите строку `data/event_embeddings.npy` из
`.gitignore` и закоммитьте сам файл.

### Шаг 5. GitHub-репозиторий

Создать репозиторий и запушить текущий код. Решите: **публичный или приватный**
— если приватный, Streamlit Community Cloud всё равно сможет деплоить из него
(нужна авторизация GitHub при подключении), но ссылка на само приложение
формально общедоступна в любом случае, если не включить отдельно защиту паролем
на бесплатном тарифе Streamlit Cloud (уточните это в процессе — политика может
меняться).

### Шаг 6. Деплой на Streamlit Community Cloud

1. share.streamlit.io → New app → выбрать репозиторий, ветку, путь к `src/app.py`.
2. Streamlit Cloud сам поставит зависимости из `requirements.txt` — учтите, что
   `sentence-transformers`+`torch` тяжёлые: первый деплой может занять заметно
   больше времени, чем обычный Python-проект, и упереться в лимит памяти
   бесплатного тарифа (~1 ГБ) — если деплой падает по памяти, это ожидаемый
   риск тяжёлого ML-стека на бесплатном хостинге, а не баг в коде; тогда стоит
   обсудить с Claude Code, что урезать (например, не грузить модель, если
   эмбеддинги уже посчитаны и нужен только `model.encode()` для запроса —
   отдельная оптимизация, не обязательная сейчас).

### Шаг 7. Проверка задеплоенного приложения

Откройте публичную ссылку в браузере (не `localhost`) — проверьте те же сценарии,
что и локально: фильтры, клик по карте, поиск по смыслу. Если поиск недоступен
(предупреждение вместо результатов) — проверьте, попал ли `event_embeddings.npy`
в репозиторий (шаг 4).

## Как использовать Claude Code на этом этапе

- Для шага 2 (цвет по категории) — попросите объяснить, почему pydeck принимает
  имя колонки датафрейма в `get_fill_color`, а не только статичный список — это
  общий паттерн pydeck/deck.gl: большинство визуальных параметров слоя можно
  либо зафиксировать, либо связать с данными построчно.
- Если деплой упадёт с ошибкой — вставьте текст ошибки целиком и попросите
  объяснить, что она значит, прежде чем менять код наугад.

## Проверка

1. Вкладка браузера показывает "KidsMap Moscow" с иконкой, а не голое "Streamlit".
2. Маркеры на карте окрашены по категории, есть легенда с расшифровкой цветов.
3. `data/event_embeddings.npy` закоммичен, `.gitignore` обновлён.
4. Код запушен в GitHub-репозиторий.
5. Приложение открывается по публичной ссылке Streamlit Cloud, а не только на
   `localhost`.
6. На задеплоенной версии работают фильтры, клик по карте и поиск по смыслу.

На этом основной путь туториалов (1-7) пройден. Расписание (автозапуск сбора
данных) осталось за скобками — при желании можно вернуться к нему отдельно,
план уже намечен в начале этого файла.
